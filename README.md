# 小學互動教室

給國小孩子用的互動教學網站：動畫講解加上練習題，有語音、有星星進度。
目前有一年級上學期數學（12 個單元與 2 個總複習）和一個英文試玩單元。

網站網址：https://spyua.github.io/elementary-school/

## 給爸媽：怎麼使用

### 打開網站

用 Chrome、Edge 或 Safari 打開上面的網址。
第一次進入單元時按「▶ 開始」並打開喇叭，才會有語音。
語音用的是裝置內建的朗讀功能，各裝置的聲音略有不同；沒有語音時仍會顯示字幕。

### 安裝到平板

裝起來之後，桌面上會有圖示，打開時像一般 App 一樣全螢幕。

- **iPad / iPhone**：用 Safari 打開網站 → 點分享按鈕 → 選「加入主畫面」。
- **Android**：用 Chrome 打開網站 → 點右上角選單 → 選「安裝應用程式」（或「加到主畫面」）。

### 下載教材，離線使用

1. 在有網路的時候打開首頁。
2. 展開「📥 下載教材，離線使用」，勾選要用的年級與科目，按下載。
3. 下載完成後，沒有網路也能打開這些單元。

沒有下載的單元，離線時會顯示提示，連上網路後再打開即可。

### 期中考、期末考

一上數學的學期畫面分成兩組，每組最後一張是考試卡：

| 考試 | 範圍 | 主題 |
|---|---|---|
| 📝 期中考 | 第一～五章（10 以內的數、比長短、順序與多少、分與合、認識形狀） | 森林探險 |
| 📝 期末考 | 第六～九章（10 以內的加法、10 以內的減法、30 以內的數、時間） | 遊樂園探險 |

「🏆 學習加油讚」（全冊總複習）放在期末組，排在期末考卡片前面，可以當考前暖身。

考試怎麼進行：

- **每份 20 題，每題 5 分，滿分 100 分。** 每次打開都重新出題，每一章都會考到固定題數。
- **像紙本考試一樣，作答時不顯示對錯。** 孩子選好答案後按「✔ 好了」，畫面只會說「收到！」，答對答錯的音效和動畫都一樣。
- **每題前有一小段開場動畫**（約 1 秒，點一下畫面可略過）。每一章是一個「區」，做完會到休息站，看看收集到的小物，按「繼續 ▶」再出發。
- **交卷後才看分數。** 結果頁先慶祝做完，再顯示分數和獎盃或獎牌，最後列出「再看一次」的錯題卡。
- **點錯題卡可以看講解。** 畫面會重畫同一題：灰色圈是孩子選的答案，綠色圈是正確答案，接著播講解動畫。
- 結果頁下方可以「🔁 練習這些題型」（把錯的題型拿去一般練習）或「📝 再考一次」。

給爸媽的小提醒：

- 考試沒有中途存檔，離開就結束，下次會出一份新的。
- 不計時，也不記錄作答時間。
- 作答內容只放在記憶體裡，離開考試就清掉。只有星星數（100 分 3 顆、80 分以上 2 顆、其他 1 顆）會跟其他單元一樣存在這台裝置的瀏覽器。
- 題目都是原創的練習題，角色用小熊、小兔這些動物，不是任何出版社的考題。

### 備份進度（匯出／匯入）

進度只存在這台裝置的瀏覽器裡，不會上傳到任何地方。
清除瀏覽資料或換裝置，進度就會不見，所以建議定期備份：

1. 點右上角的「孩子檔案」按鈕。
2. 按「📤 匯出進度」，會下載一個進度檔。
3. 到新裝置（或清除資料後）打開同一個畫面，用「📥 匯入進度」選擇剛才的檔案。

選錯檔案時會顯示「這不是進度檔」，原本的進度不會被改動。

## 給開發者

### 本機開發

需要 Node.js 22 以上。

```bash
npm i            # 安裝套件
npm run dev      # 開發伺服器，修改後自動重新整理
npm test         # 單元測試（Vitest），包含隱私檢查
npm run e2e      # 瀏覽器測試（Playwright），會先自動建置
npm run lint     # ESLint
```

第一次跑 e2e 前要先安裝瀏覽器：`npx playwright install chromium`。

### 部署

推送到 `main` 後，GitHub Actions（`.github/workflows/deploy.yml`）會：

1. 跑單元測試與瀏覽器測試。
2. 用 `BASE_PATH=/<儲存庫名稱>/` 建置。
3. 發布到 GitHub Pages。

本機想模擬部署後的網址，可以這樣跑：

```bash
BASE_PATH=/elementary-school/ npm run build
npx vite preview --base /elementary-school/
# 打開 http://localhost:4173/elementary-school/
```

### 新增一個單元

每個單元由兩個部分組成：

1. **在目錄登記**：在 `src/content/catalog.js` 對應的學期包裡加上單元的中繼資料，
   包括固定 ID（`id`）、`key`、名稱、圖示、說明、課綱代碼、給爸媽的提示，並放進 `chapters`。
   固定 ID 一旦提交就不要再改，進度存檔用它當鍵值。
2. **寫學期包內容**：在學期包（例如 `src/content/math/g1a/`）加上這個單元的動畫場景與練習題型，
   並在學期包的 `index.js` 匯出。

不想自己寫繪圖程式時，可以直接用 `src/templates/` 的範本：

- `explainer`：一步一步顯示圖片與文字的講解動畫。
- `choice`：看圖或看字選答案。
- `listen`：聽語音選答案。
- `match`：連連看。

`src/content/english/g1-demo/index.js` 就是只用範本做出的完整單元，可以照著改。

新增一整個學期時，在 `catalog.js` 的 `PACKS` 加一個學期包，用 `load()` 延遲載入它的內容。
課綱對照文件放在 `docs/curriculum/`。

### 新增一份考試

考試由兩個部分組成：

1. **在目錄登記**：學期包的 `exams` 加一筆（`key`、固定 ID、名稱）。
   章節加上 `term`，`terms` 列出分組標題與組尾的考試卡。
2. **寫藍圖（blueprint）**：藍圖是一份資料，說明每一區（通常一章一區）要出哪些題型。
   一上數學的藍圖在 `src/content/math/g1a/exam.js`。每個 `slot` 出一題，所有 slot 加起來必須剛好 20 個。

出題與考試畫面由共用引擎負責，不用另外寫：

- `src/engine/paper.js`：依藍圖出題，每題配一個亂數種子。
- `src/engine/exam.js`：封面、每題開場、休息站、交卷、結果頁、錯題卡。
- `src/engine/practice.js`：作答與判分（考試分支都包在 `if (P.cfg.exam)` 裡）。

錯題重看時，用同一個種子重建同一題，所以畫面和孩子作答時完全一樣。

### 素材來源

所有圖片、音效、字型都用開源授權（MIT、CC0、OFL 等）。完整清單與授權在網站的「致謝與授權」頁，資料來源是 `src/content/credits.json`。

| 資料夾 | 放什麼 | 怎麼離線 |
|---|---|---|
| `public/emoji/` | 教材專屬的圖：數數物件、動物、生活事件卡、考試主題圖 | 列進學期包的 `assets`，按「下載教材」時抓取 |
| `public/ui/` | 所有學期包共用的引擎圖：吉祥物小熊、星星、獎盃、獎牌、紙花 | 跟 App 外殼一起預先快取 |
| `public/sfx/` | 答對、答錯、得星、點擊音效（Kenney，CC0） | 跟 App 外殼一起預先快取 |

圖片是 Microsoft Fluent Emoji 的 Flat SVG（MIT），由 `scripts/fetch-fluent.mjs` 下載：

```bash
node scripts/fetch-fluent.mjs   # 已經存在的檔案會略過，可以放心重跑
```

新增一張圖的步驟：

1. 在 `scripts/fetch-fluent.mjs` 的對照表加一行「本地檔名 → Fluent 資料夾名稱」，再執行一次。
2. 在 `src/engine/emoji-map.js` 加上「emoji 字元 → 檔名」對照。學期包的離線清單會自動包含它。
3. 在 `src/content/credits.json` 的 Fluent Emoji 那一筆 `usage` 補上「本地檔名 ← Fluent 原名」。

單元測試會檢查：對照到的檔案都存在、離線清單涵蓋全部、`public/emoji` 加 `public/ui` 小於 1 MB。
