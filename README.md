# 小一數學互動教室（一上・翰林版）

## 內容
- `index.html`：互動教學網站（9 章 12 單元＋總複習），單一檔案，直接用瀏覽器開啟即可。
- `小一上數學課綱.md`：一上課綱、單元重點、常見錯誤、在家練習、版本對照。

## 使用方式
1. 解壓縮後，雙擊 `index.html`（建議 Chrome、Edge 或 Safari）。
2. 首次進入單元按「▶ 開始」並打開喇叭，才會有語音。
3. 平板也可使用：把 `index.html` 傳到平板，用瀏覽器開啟。

## 注意
- 不需安裝、不需網路；有網路時會載入圓潤字型，沒網路則使用系統字型。
- 語音使用瀏覽器內建中文朗讀，各裝置聲音略有不同。
- 星星進度存在該瀏覽器中，換裝置或清除瀏覽資料會重新計算。
